# She Connects 🌷

**Share resources. Build connections. Create opportunities.**

## 💡 About She Connects

She Connects is a women-focused web platform created to encourage collaboration, empowerment, and community support. It provides a shared space where women can connect with one another, exchange useful resources, find mentors, and discover opportunities that support their personal, academic, and professional development.

Many women have valuable skills, knowledge, resources, and opportunities but may not always have access to the right networks or support systems. She Connects aims to bridge this gap by making it easier for women to help one another, share what they have, and grow together.

The platform is being developed as a functional web application using HTML, CSS, JavaScript, PHP, and MySQL.

## 🎯 Our Mission

Our mission is to create a supportive digital community where women can access resources, build meaningful relationships, learn from one another, and discover opportunities for growth.

She Connects is built around a simple idea: **when women connect and support one another, everyone has the opportunity to grow.**

## ✨ Core Features

### 🤝 Resource Sharing

Users can share resources with other members of the community. These may include textbooks, study materials, clothing, equipment, business supplies, and other useful items.

The resource-sharing feature encourages collaboration by allowing users to offer items, browse available resources, and submit requests to give, lend, or exchange items.

### 🌱 Mentorship and Networking

Building the right connections can make a meaningful difference in someone's journey. She Connects aims to help users discover people with similar interests, relevant experience, or skills they would like to develop.

Users can create profiles, share their skills and interests, explore potential mentors, and send connection requests to build supportive professional and personal networks.

### 🚀 Opportunities

She Connects provides a space to discover and share opportunities that can help women move forward in their careers, education, and businesses.

Opportunities may include:

- Internships and job openings.
- Scholarships and educational programmes.
- Workshops, events, and networking sessions.
- Entrepreneurship programmes and business opportunities.

Where available, listings can include descriptions, application deadlines, and links to external websites.

### 👤 User Profiles

Member profiles help users introduce themselves to the community. Profiles can include relevant skills, interests, educational or professional backgrounds, and areas where they can offer or need support.

### 📩 Request Management

The platform aims to make interactions easier by allowing users to submit and manage resource or connection requests. Depending on the feature, users can review requests and accept or decline them.

## ⚙️ How It Works

She Connects connects the user interface to a PHP backend, which communicates with a MySQL database.

Users interact with the website through their browser. PHP processes supported actions, such as submitting forms or creating requests, while MySQL stores and retrieves the relevant information.

This structure provides a foundation for user accounts, resource listings, connection requests, and opportunity listings. Features are implemented progressively as development continues.

## 🚀 Getting Started

### Requirements

- XAMPP with Apache and MySQL.
- PHP 8 or later.
- A web browser and code editor.

### Installation

1. Clone the repository into your XAMPP `htdocs` directory.
2. Start Apache and MySQL in the XAMPP Control Panel.
3. Create the required database through phpMyAdmin.
4. Import the project's SQL file, if included.
5. Configure the database credentials in the application's database connection file.
6. Open the application at `http://localhost/sheconnects/`.

Make sure the database name, file paths, and setup instructions match the actual project files.
